# Android-Attendance-App
# 📱 Student Attendance Management System

This Android application is a **Student Attendance Management System** built as part of the CMAD (Concept of Mobile Application and Development) course at **VIT-AP University**. It enables faculty members and administrators to add and manage students, assign faculty, take daily attendance, and view attendance records efficiently through a mobile-friendly interface.

---

## 📌 Features

- 👩‍🏫 Faculty and Admin login functionality
- 🎓 Add/view student and faculty profiles
- 🗓️ Create attendance sessions with branch, year, subject, and date
- 📋 Take attendance per student with present/absent marking
- 📈 View total attendance per session and student
- 🧠 SQLite database for offline data storage
- 💡 Intuitive user interface using Android XML layouts

---

## 📁 Folder Structure

├── app/ │ ├── manifests/ # AndroidManifest with declared activities │ ├── java/com/android/attendance/ │ │ ├── activity/ # All app activities (e.g., Login, AddStudent, ViewAttendance) │ │ ├── bean/ # Data model classes (StudentBean, FacultyBean, etc.) │ │ ├── db/ # SQLite DBAdapter for CRUD operations │ │ └── context/ # Application context for global data │ └── res/ # Layout XML files, drawable icons, and resources

---

## 🛠️ How It Works

- **Login**: Admin logs in with fixed credentials (`Madhu/Madhu786`) and faculty logs in via credentials stored in DB.
- **Add Faculty/Students**: Admin can add new faculty and students with department/year info.
- **Attendance Session**: Faculty selects branch/year/subject and date to create a session.
- **Take Attendance**: Attendance is marked per student with options to mark present/absent.
- **View Reports**: Attendance can be viewed per session or per student.
